HTML INTRODUCTION

HTML means HyperText Markup Language. It describes the structure and meaning of web-page content; CSS is used for presentation and JavaScript can add behavior.

A basic document starts with <!DOCTYPE html>, then the <html> element. The <head> contains page information such as the character encoding, viewport settings, title, and links to stylesheets. The <body> contains the content shown in the browser.

I practised headings, paragraphs, links, buttons, and other text elements. Headings should describe the page structure, rather than being chosen only for their visual size.
